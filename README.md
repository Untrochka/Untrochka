## What I do

> Built your app with Lovable, Cursor or Claude Code and got stuck at 70–80%? I take it to launch: fix the bugs, clean up the code, add a real database and auth, deploy it properly.

- ~3 years in production — 1.5 years at **Noor**, building three admin systems for a delivery service (merchant panel with billing logic, central operations panel with live GPS tracking, customer tracking site).
- I build web apps, admin dashboards, online stores, booking systems and **Telegram Mini Apps**.
- I use AI tools every day myself (Claude Code), so I know where they cut corners and what breaks with real users.
- I work in milestones: first a plain review of what's broken, then a working core, then iteration.
